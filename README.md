My Reflection on This Lab
In this lab, I worked on setting up a MongoDB Atlas cluster and connecting it to my 
Node.js and Express application. At first, I had to carefully follow each step, 
especially when creating the database user and setting up the connection string.
I also learned how important it is to use environment variables to keep sensitive information secure.

While working on the project, I faced some small issues with the database connection,
but I was able to fix them by checking my .env file and making sure everything was configured correctly. This helped me understand how to debug connection problems.
